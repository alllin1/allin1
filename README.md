# Allin1

Allin1 is the place your business chats with its agents. This page installs the program for a computer. The app, the account, and the subscription live at [allin1app.com](https://allin1app.com).

## Install

Windows, in PowerShell:

```powershell
irm https://allin1app.com/install.ps1 | iex
```

Mac and Linux:

```sh
curl -fsSL https://allin1app.com/install.sh | sh
```

Open a new terminal and run:

```sh
allin1
```

`/login` opens allin1app.com so you can sign in and pick a location. A sentence in that session goes to your agent. `/folder` chooses the folder on this computer. `/update` replaces the program when a newer one is ready. Your folders and your sign-in stay where they are.

## Sign up

Create an account at [allin1app.com](https://allin1app.com).

A subscription is required before the program signs in on a computer. Without one, the browser opens the pricing page and the program stays signed out.

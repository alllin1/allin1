## Put it on the computer

Windows, in PowerShell:

```powershell
irm https://allin1app.com/install.ps1 | iex
```

Mac and Linux:

```sh
curl -fsSL https://allin1app.com/install.sh | sh
```

Open a new terminal and run `allin1`.

| Command | What it does |
| --- | --- |
| `/login` | Opens allin1app.com and connects one location |
| `/folder` | Chooses the folder agents may use on this computer |
| `/update` | Replaces the program when a newer one is ready |

`/update` replaces the program file only. The folder you granted and the sign-in stay where they are.

The download is checked against its SHA-256 checksum before it is kept. If the file does not match, or this computer cannot check it, nothing is installed. The installer writes one program into your user folder. It does not ask for an administrator password.

A subscription is required before the program signs in. Without one, the browser opens pricing and Allin1 stays signed out.
